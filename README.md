# 흡연 여부와 건강 지표의 상관관계 분석

> **4개 가설 모두 p < 0.0001** | 통계적 유의성 검증 | 임상 도메인 지식 기반 해석

---

## 프로젝트 개요

흡연자와 비흡연자 간 주요 생체 지표 차이를 데이터로 직접 규명하고  
통계적 유의성을 검증한 분석 프로젝트입니다.  
물리치료사로서 임상 현장에서 흡연 환자와 비흡연 환자의 차이를 직접 경험한 배경으로  
가설 설정부터 결과 해석까지 도메인 지식을 적극 활용하였습니다.

| 항목 | 내용 |
|------|------|
| 과제 유형 | 통계 분석 (가설 검정) |
| 데이터셋 | 건강검진 데이터 7,000건 → 전처리 후 6,950건 |
| 분석 변수 | 혈압 · 헤모글로빈 · 간 효소율 · 콜레스테롤 · LDL · HDL · 중성지방 · 충치 여부 |
| 검정 방법 | t-검정 (독립표본) · 카이제곱검정 |
| 최종 성과 | **4개 가설 모두 p < 0.0001 — 통계적 유의성 확인** |

## 데이터 전처리

| 단계 | 내용 |
|------|------|
| 초기 데이터 | 7,000건 |
| 결측치 처리 | 나이대별 중앙값으로 대체 (단순 제거 시 편향 우려) |
| 이상치 처리 | 3.0 × IQR 기준 50건 제거 (의료 데이터 특성상 보수적 기준 적용) |
| 최종 데이터 | **6,950건** |

## 가설 검증 결과

### 가설 1 — 흡연과 충치 발생
- **검정 방법**: 카이제곱검정 (범주형 변수)
- **결과**: 흡연자 그룹의 충치 발생 빈도가 비흡연자 대비 통계적으로 유의하게 높음
- **p-value**: p < 0.0001 → **가설 채택** ✅

### 가설 2 — 흡연과 헤모글로빈 수치
- **검정 방법**: 독립표본 t-검정
- **결과**: 일산화탄소 결합으로 인한 산소 부족 → 보상 작용으로 헤모글로빈 수치 상승 확인
- **p-value**: p < 0.0001 → **가설 채택** ✅ (4개 지표 중 가장 강력한 상관관계)

### 가설 3 — 흡연과 간 효소율
- **검정 방법**: 독립표본 t-검정
- **결과**: 통계적 유의성은 있으나 효과 크기 미미 (복합 요인 영향으로 판단)
- **p-value**: p < 0.0001 → **부분 채택** ⚠️

### 가설 4 — 흡연과 지질 대사 (HDL · 중성지방 · LDL)
- **검정 방법**: 독립표본 t-검정
- **결과**: 중성지방 상승 및 LDL/HDL 불균형 — 심혈관 건강에 악영향 확인
- **p-value**: p < 0.0001 → **가설 채택** ✅

## 🗺 히트맵 분석

- **강한 양의 상관관계**: 콜레스테롤 ↔ LDL
- **핵심 발견**: 흡연 ↔ 헤모글로빈이 단일 변수 기준 가장 강력한 상관관계
- **그룹별 비교**: 흡연자와 비흡연자의 지표 연관 구조 자체가 다름을 확인
